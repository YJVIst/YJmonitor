# Rust 版本安全边界与依赖告警

主控 0.11.4，Agent 0.2.3。应用源码禁止 unsafe；底层操作系统与密码库仍属于依赖信任边界。Rust 不能消除配置错误、权限滥用或所有逻辑漏洞。

## RUSTSEC-2023-0071 / CVE-2023-49092

主控依赖树中 `rsa 0.10.0-rc.18` 被 Cargo Audit 标记为 Marvin 时序侧信道告警，上游目前没有修复版本。原始扫描必须保留。官方公告：https://rustsec.org/advisories/RUSTSEC-2023-0071.html

本程序是 SSH 客户端，不提供 RSA 私钥解密或 RSA 私钥签名服务：首次部署使用密码认证；受管 SSH 私钥只生成 Ed25519；读取历史私钥后，在认证和建立 Agent 隧道之前检查算法，非 Ed25519 拒绝使用。RSA 特性仅为已有服务器的 RSA-SHA2 主机公钥验签保留。应用不配置 RSA 客户端私钥，也不支持导入任意管理私钥。

据此，当前应用路径没有该告警所描述的 RSA 私钥运算入口；这是针对当前代码和配置的可达性判断，不代表上游包已修复。未来增加 RSA 私钥、SSH 服务端或通用密钥导入时必须重新评审。

## 主要保护

- TLS 验证证书链与主机名，Agent 使用 WSS、独立节点密钥；禁止跳过证书验证。
- 管理密码 bcrypt，登录限流持久化；TOTP 启停需验证当前身份，动态码防重放。
- 管理接口要求有效会话；写操作校验 Origin 和 CSRF；Cookie 使用 Secure、HttpOnly、SameSite=Strict。
- 内部健康与网关接口验证由私密主密钥派生的凭据；HTTP 直连和 HTTPS 会话使用不同的 Cookie。正式使用建议配置 HTTPS 反向代理并让主控回环监听。
- 首次部署核对并固定 SSH 主机指纹；变更后须管理员明确核对新指纹，确认前拒绝部署。
- 终端票据短期有效、单次使用并绑定管理会话；退出、用户名、密码或 MFA 变更撤销活动终端。
- Agent 隧道仅连接节点回环 SSH 端口；消息大小、连接数、速率、队列和失联等待均有界。
- SFTP 按登录 SSH 用户权限操作；编辑仅限 256 KiB UTF-8 普通文件，校验版本冲突、保留权限与扩展属性，临时文件原子替换，不生成原文件备份。
- 节点凭据及 Telegram Token 使用 AES-256-GCM 加密，状态写入使用 0600 临时文件、同步与原子替换。
- 无数据库服务；storage 必须位于 public 外。主控使用独立的低权限系统用户。

测试报告记录实际验证范围。快速扫描和压测不能保证不存在未知漏洞，也不等同于长期稳定性认证。

- 根权限更新器不接受任意 URL、脚本或目录；发布签名与归档路径均验证，失败回退代码与状态。
- 所有扫描结果按实际结果披露；RUSTSEC-2023-0071 仍存在于依赖清单，不作为“已修复”处理。

## 0.6.0 新增边界

文件传输通过现有 Agent WSS 与 SSH 通道，限制为单会话一项传输、单文件 128 MiB；分块、偏移及传输标识校验，取消时尽力清理临时文件。上传和重命名拒绝同名覆盖。进程与服务查询采用固定命令，服务名白名单校验，不接受任意执行参数。

异地备份仅接受公网 HTTPS，解析后固定连接 IP、禁止重定向与环境代理。存储凭据加密保存，备份在本地加密后上传；下载与上传读回均校验 SHA-256。敏感操作仍要求近期身份验证，后台轮询仅返回脱敏状态。


## 0.7.0 新增边界

主题配置写入与预览均要求管理员会话及 CSRF 校验；图片仅接受有界 PNG/JPEG/WebP，服务端解码后重新编码，禁止 SVG/HTML 上传。局部 CSS 使用限定选择器、属性和值范围，禁止外部资源与执行内容。主题配置随加密备份保存，恢复时重新校验。金额以整数最小货币单位计算，支出与供应商信息仅在管理接口公开。安装与更新保留 SELinux enforcing，按限定目录恢复标签。


## 0.8.1 新增边界

SSH 使用普通 PTY shell；断线、关闭、退出或撤权均结束对应连接，不创建、附着或自动恢复 tmux。旧版 terminal-sessions 接口已移除，旧 resume 握手被拒绝。升级仅清理本面板 0.8.0 记录的独立 socket 和精确会话名；不会清理其他 tmux。

文件续传记录与节点、随机文件工作区、管理员登录会话和认证版本绑定；同一工作区只能由一个连接使用，断线后最多保留 30 分钟，私密存储 0600；上传临时文件的路径只能由服务器生成。恢复核对客户端和远端前缀 SHA-256，完成上传再次核对完整远端文件。每项传输按 128 KiB 分块，文件最多 2 GiB；浏览器队列、服务端记录和活动通道均有数量上限。编辑仍限制 256 KiB，并保留冲突检测、不生成原文件备份。

下载缓存位于浏览器 OPFS。下载 Service Worker 只在 /assets/ 下响应随机、单次使用的附件地址，通过授权页面专用 Worker 的 MessagePort 接收有界数据流，不读取 OPFS、不代理其他接口、不缓存页面。页面 CSP 仅补充同源 worker-src 与 frame-src；仍禁止第三方脚本、跨站嵌入与对象内容。浏览器本地缓存同样属于管理员设备数据，请保护设备和浏览器账户。

一次性接入命令有效 10 分钟，主控只存临时凭据摘要；原子领取后不可重放，管理员登出、撤权、重新生成或撤销会使未提交的授权失效。公开领取接口使用临时 bearer 凭据并限流，无需浏览器 Cookie；生成和撤销接口继续校验管理员身份与 CSRF。安装包由主控从签名发布清单和已校验二进制生成，经 HTTPS 传送；归档严格限制名称、类型、数量和大小。

## 0.9.0 主题包

主题导入和导出要求管理员身份；导入另校验 CSRF 与 Origin。主题包仅接受 3 MiB 以内的 JSON 数据，拒绝未知字段、脚本、文件路径、嵌套运行信息、外部资源地址与不支持的版本。导入只返回规范化的预览；保存再检查当前版本并写入配置。图片有解码尺寸、内存和并发限制，重新编码后保存。明暗配色仅能设置列出的颜色变量，局部 CSS 继续采用选择器、属性和值白名单。主题不能加入 HTML、JavaScript、PHP 或任意 CSS。导出只包含外观数据。

山水四季的既有设置与旧备份在载入时迁移为四季，随后进行原有验证。此版本不改变节点密钥、WSS 认证或 SSH/SFTP 协议。


## 0.9.1 终端连接

已授权且心跳正常的终端不会因为 10 分钟没有键盘输入或累计输出 64 MiB 而结束。输出仍限制为每秒 256 KiB，保留有界队列、输出确认及浏览器 2000 行回滚上限。主控每 25 秒发送 WebSocket Ping，75 秒未收到对应 Pong 才判定失联，重试不会延长失联期限。有效 Pong 仅更新既有授权的活动时间，不延长登录的 8 小时绝对期限，也不能恢复已撤销的会话。SSH 使用协议心跳检测存活。关闭窗口、主动断开、退出登录、凭据撤销和真实断线仍会结束远端 shell；不恢复已移除的终端保留或自动重连功能。操作记录包含关闭原因与连接秒数，不记录终端内容。

## 0.9.2 心跳隔离与有限重连

终端输入由独立任务按顺序写入 SSH，最多缓存 16 条、每条不超过 16 KiB；超量关闭，不建立无界缓冲区。WebSocket 接收循环不再等待 SSH 写入、窗口调整或文件错误响应，从而持续处理 Pong、输出确认和关闭消息。心跳及 Pong 使用独立有界队列，在发送任务中优先处理；控制帧另限速为每秒 16 条。网络本身持续不可写时仍按期限关闭，不承诺在物理网络中断时维持传输。

浏览器仅对暂时性传输故障，按 2、5、10 秒最多重试三次；连接稳定 60 秒后恢复重试额度。每次重新申请绑定当前登录的单次票据，建立全新 SSH 会话，不恢复旧 shell、不重发输入。主动关闭、取消、正常远端退出及明确认证失败不自动重连。取消与过期回调不能在标签移除后新建连接。所有重试继续受既有权限、连接数量、请求频率、主机指纹和登录绝对期限约束。

节点延迟探测的迟到、重复或不匹配 Pong 不再直接撤销整个 Agent 连接；只有当前挑战的及时应答可更新延时。有效监控数据的 15 秒期限、消息校验与速率限制保持生效。操作记录补充节点连接错误原因，不记录令牌或终端内容。


## 0.10.1 独立 Rust Web 与受限 Shell 恢复

Nginx + Rust 版将公开静态资源嵌入主控，不把文件系统路径映射为 URL。Nginx 仅代理到回环地址，覆盖来源 IP 头并清除外来的内部网关头；静态、页面和 API 保留 CSP、安全 Cookie、认证与 CSRF/Origin 限制。安装器凭私有状态目录内的随机所有权链接、HttpOnly Cookie 和 CSRF 安装，单写入者与有界请求体防止并发覆盖，认证文件提交后锁定安装。包内不包含站点密码、节点凭据或签名私钥。

Shell 标识为随机 256 位，仍需要单次终端票据及原始管理员登录、认证版本、节点一致。标识只保存在终端页面内存，不放入 URL 或浏览器持久存储。不同登录不能接管或关闭彼此会话。断线保留五分钟；主动关闭、退出登录、设备撤销、绝对登录期限与后台清理继续生效。主控重启后不允许新登录接管旧会话。远端 tmux 使用本实例独立命名空间，过期任务按会话定位，仅处理本面板创建的 Shell。断线不会自动重发命令。

SSH 保活和重新协商分别计时；重新协商期间不发送普通保活请求，不累计保活失败，重新协商另限时 60 秒。变更只涉及上游 russh 的客户端调度，不修改加密算法、主机密钥固定、密钥交换或认证验证。补丁来源和范围见 source/vendor/RUSSH-PATCH.md；测试覆盖延迟重新协商、协商超时及正常保活无响应。

终端、浏览/编辑、传输使用各自按需建立的 SSH 连接，文件超时只关闭文件连接。所有通道仍有有界队列、速率限制、授权检查和同一 Agent 的连接数限制。扩大连接上限不取消流控。

本独立仓库的 root 更新器固定为 YJVIst/YJmonitor 的 v* 发布，拒绝 PHP 包及其他仓库地址；更新器目录与 systemd 服务使用独立 Rust 前缀。私有状态必须位于专用实例目录的 control 子目录。签名、长度、哈希、解压路径验证与失败回退继续启用。扫描范围、已知 RSA 告警与实测边界见本版本验收报告，不能据此保证不存在未知漏洞。

## 0.10.2 终端历史

终端改用 tmux 控制模式传送原始 PTY 输出，浏览器缓存最多 5,000 行。恢复快照和控制协议均有长度限制，输入使用逐字节十六进制编码，避免 tmux 命令注入；保留原会话归属、CSRF、Origin、流控和主动关闭规则。触摸滚动完全在浏览器内处理。详见 [终端回滚记录说明](终端回滚记录-0.10.2.md)。


## 0.11.0 终端监测与链路

终端新增的系统负载、磁盘容量和进程列表继续通过已认证的独立 SSH 文件连接读取，遵守节点的主机指纹和当前 SSH 用户权限。查询使用固定脚本；磁盘只读本地文件系统计数，不递归统计目录。读取有输出、时间、刷新频率和缓存上限，进程名、挂载路径及路由结果仅按文本渲染。命令名称使用进程名，不公开完整命令行参数。

路由与 TCP 连通性接口需要管理员会话、CSRF/Origin 验证及该登录当前持有的、已连接的 SSH 文件会话。目标只能来自已登记的节点，不接受地址、端口或命令参数。tracepath 在普通服务用户下运行，不添加 root 或原始套接字能力；子进程、输出、并发和缓存数量均有上限。

路由公网 IP 的 ASN 归属从固定的 RIPEstat HTTPS 接口读取，禁止重定向，设置超时、响应大小、并发和日限额。私网及保留地址不发送到外部查询服务；失败显示未知。细节见 [终端工作区说明](终端工作区-0.11.0.md)。本次未引入新的 Rust 依赖，既有 RSA 告警仍按本文件披露。


## 0.11.1 可选 HTTPS 管理

新增功能只在 root 管理菜单中执行，未新增公开 HTTP API。域名严格校验；子进程采用参数数组，不使用 shell 或 eval。现有 Nginx 的同名站点和手动修改受归属与摘要检查保护；证书申请和健康检查失败会恢复配置。Certbot 使用独立虚拟环境与私有 ACME 目录，Cloudflare Token 不进入命令行，续期只信任受限凭据文件，客户端 API 地址固定为官方 HTTPS 地址。Nginx 仅信任官方 Cloudflare 地址段提供的真实 IP，清除外来内部网关头；WSS 和文件流经回环地址代理。详见 [自动 HTTPS](自动HTTPS.md)。

## 0.11.2 重装后的 SSH 指纹更新

重装系统或主动轮换 SSH 主机密钥后，检查接口返回新旧指纹，由管理员核对并勾选确认后更新。检查凭据只在原登录会话内有效，五分钟过期，成功后不能重复使用；信任记录在检查后有任何变化时必须重新核对。正在部署时拒绝替换指纹。匿名访问、缺少 CSRF、未明确确认或自行提交主机密钥均被拒绝。

更新只针对对应 IP:端口的安装信任记录，不批量清除其他主机指纹，也不自动改写现有节点的终端凭据。部署仍在严格验证新主机密钥后发送 SSH 密码。取消操作保留原记录；原子保存失败不会只更新内存。操作记录保存地址及新旧 SHA-256 指纹，不保存 SSH 密码。

## 0.11.2 管理员用户名与终端界面

修改用户名要求管理员登录、Origin/CSRF 校验及当前密码验证，与修改密码共用每 15 分钟 5 次的密码验证额度。新用户名按与安装器相同的规则验证；拒绝额外的安全字段。保存通过认证版本比较和原子写入完成，随后撤销旧登录和终端会话，为当前浏览器生成新的会话。密码哈希、二步验证密钥、计数器及恢复码均保留；操作记录不包含密码。

底部常用命令仅按纯文本展示名称；点击运行只发送已有命令 ID，脚本仍由主控在当前授权 SSH 会话内查找并执行。断线时按钮禁用，异步结果不能覆盖已销毁的终端标签。移除手动重连按钮不改变有限自动重试、会话归属和关闭标签时的撤销规则。模态滚动限制仅影响浏览器布局，没有放宽认证、文件权限或主题 CSS 白名单。

## 0.11.2 群组通知、通道隔离与安装

群组启用前校验 Bot 身份、群组 ID / 类型、机器人管理员权限，发送前再次检查。群组事件服务端限定为节点状态和显式测试，不接受登录或续费事件；个人与群组独立排队和保存结果。Token 沿用加密存储，固定 HTTPS API 不重定向，响应有界，错误不包含请求 URL。更换 Token 使群组验证失效。保存需要管理员认证、Origin / CSRF，远程验证有速率限制，异步完成后重新校验会话和设置版本。

文件附属 WSS 必须绑定当前管理员已有的、处于连接状态的终端文件会话，核对登录所有者、认证版本和节点；旧连接清理不能撤销后续新连接。文件断线不结束原 Shell，但关闭父终端或撤销登录会取消文件连接。资源查询使用独立 SSH 工作线程，控制帧优先于批量数据，所有队列、帧、请求数和写入时间仍有上限。没有取消 TLS、主机指纹、会话绝对期限或远程文件权限检查。

服务准备脚本仅以 root 创建指定的低权限账号和私有目录，检查程序父目录、软链接、已有账号与目录归属，拒绝接管无关目录。sudo YJ 和兼容命令以原子方式安装，只移除完全匹配的本项目命令，不覆盖外部同名程序。仓库迁移只更改固定仓库标识，继续使用原发布公钥及归档校验。

## 0.11.3 管理员服务器筛选

状态分类只使用当前管理员已经获准读取的节点数据，不新增接口、权限或持久化字段。数量和服务器名称通过 DOM 文本渲染，筛选控件独立于公开看板。筛选后隐藏排序入口，避免修改不可见服务器的相对顺序；全部视图沿用原有排序接口、认证与 CSRF 校验。退出登录清除筛选状态。


## 0.11.4 服务器管理与批量升级

- 服务器搜索和组合筛选在已授权管理员页面执行。上报、离线事件和连接错误摘要仅通过管理员节点接口返回，公开看板不包含 SSH 地址、供应商、健康摘要、任务或凭据。
- 批量升级要求管理员会话、同源 Origin、CSRF 令牌和 5 分钟内的密码 / 二步验证。请求只接收 1–1000 个不重复的节点 ID，不接受 URL、脚本、命令或二进制输入。
- 任务先原子落盘再执行，与部署共享两个并发名额。重复请求、移除中、未接入、离线、不支持架构或已有管理任务的节点不会重复排队；失败后由管理员选择重试。
- 主控重启会恢复待执行任务；任务 ID 校验防止旧执行结果覆盖新任务。升级继续验证 SSH 指纹及发布签名、版本、长度和 SHA-256。
- 通讯错误只显示固定中文摘要，未知错误不会将原始异常、密钥或令牌输出至前端。离线时间缺少事件记录时明确标记估算。
- 本次没有引入新依赖；RSA 既有告警仍按上文处理，不能宣称零漏洞。

- 管理员列表的一秒缓存仍在逐次完成会话检查后返回，并与公开数据缓存隔离。权限、CSRF 及私有数据边界没有因缓存而放宽。
- 合法 Agent 按节点限速，错误认证仍按来源 IP 限速；因此同一 NAT 后的 1000 个合法节点可以接入，错误令牌不能绕过限制。单节点仍只允许一条控制连接。
- 千节点批量升级及排序允许最多 96 KiB JSON 请求，数量、ID 唯一性与完整列表检查仍在服务端执行。其余常规接口保持原请求体限制。

- 节点移除成功后回收其管理任务。启动和创建备份时剔除不再对应当前节点的管理 / 旧凭据状态，避免历史记录累计导致千节点备份越限；审计记录继续按既有限额保留。

## 0.11.5：版本检测与 YJ 部署

主控在独立异步任务中统一检查 GitHub 正式 Release 和通过 Ed25519 验签的 Agent 清单，每小时一次；失败后五分钟重试，手动检查至少间隔一分钟。所有浏览器共享结果，不按节点数量重复外部查询。检查有总超时、响应长度限制和固定 HTTPS 下载域名边界，检查失败不表示当前已最新。安装继续校验签名、大小、SHA-256 和 SSH 主机指纹。

版本操作保留管理员会话、同源、CSRF、防重和速率限制，按产品要求取消此区域的二次密码验证。主控更新必须匹配成功检测的较新版本；Agent 升级在服务端比较已安装版本，相同、更高或未知版本不创建升级任务。Agent 仅安装主控配套的兼容版本，检测到更高配套版本时提示先更新主控。回退保持独立入口，备份、安全设置等敏感操作仍执行原身份复核。

新安装使用无登录 shell 的系统用户 YJ，程序 /opt/YJ 由 root 管理，私有数据 /var/lib/YJ 仅该服务用户可读写。root 更新器的快照独立保存在 /var/lib/YJ-update，避免放入服务用户可改名的目录。更新配置 /etc/YJ/update 与辅助程序 /usr/local/lib/YJ 由 root 管理。旧实例保留明确的兼容路径；不会接管同名外部账户、目录或命令。
