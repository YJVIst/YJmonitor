# 主控 0.11.6 与 Agent 0.2.4

本版支持在 SSH 地址中填写域名。管理员使用密码安装或重装时会接受连接对端的主机密钥，域名被错误解析时，密码可能交给错误的主机。请使用可信的 DNS 和管理网络。

看板、详情窗口和图表复用既有元素。终端和编辑器在打开时加载。公开看板轮询拥有独立的每来源限额，浏览器收到 429 后按 Retry-After 延后自动读取。节点状态写入、恢复和启动读取共用 64 MiB 限额，主控升级器在数据卷上暂存恢复内容。Agent 合并健康证明写入，首次确认和重连后及时更新证明。

## 依赖与凭据扫描

在 RustSec 数据库修订 `8b75c83` 上，原锁文件命中主控 10 项、Agent 7 项漏洞公告，两组存在重合。本版更新 TLS、证书、URL 和密码库依赖，同时处理 Tokio 与 rustix 的安全提示。更新后的两个产品锁文件均为 0 项已知漏洞；主控的 chrono 仍有一项停止维护提示。npm 对生产与开发依赖的审计为 0 项。[依赖安全说明](RUST-SECURITY.md)

源码扫描器检出的 30 处均逐条与官方 russh 0.63.3 原始包按内容核对，其中包括公开的示例和测试密钥。本版更换 Ed25519 发布公钥，旧实例按[换钥升级说明](换钥升级-0.11.6.md)迁移。

## 并发与连接验收

| 隔离场景 | 实测结果 |
|---|---|
| 1,000 个模拟节点，8 个同来源读者突发读取 240 次 | 原主控返回 120 次 429，随后会话接口也返回 429。独立配额生效后 240 次读取全部成功。公开看板用完每分钟 600 次配额时，管理会话仍可用。 |
| 128 个模拟 Agent，每 3 秒上报一次，8 个客户端每秒读取一次，共 60 秒 | 2,560 次上报全部收到回执，480 次看板读取成功，意外断线 0 次。测试使用本机回环上的主控代理后端。 |
| SSH/SFTP | 本机临时 OpenSSH 实例使用 RSA-SHA2 主机密钥和 Ed25519 用户身份，候选依赖完成主机验签、登录和隔离目录内的 SFTP 读取。 |
| Agent 0.2.4 | 实际 amd64 静态构建连接本地 TLS/WSS 测试对端。13 次回执产生 3 次健康文件更新，首次确认约 3 秒，稳定期间隔 33 秒，重连后约 3 秒。 |
| WebSocket 升级 | 已修正规范握手返回 101 时的 Connection 响应头。ARM64 主控在 QEMU 中通过普通 HTTP 和 Agent 升级握手测试。 |
| 浏览器和状态恢复 | 验证终端和编辑器首次加载失败后重试、保存后的文件通道重连、详情窗口选区与焦点、多轮相同采样零 DOM 改写，以及 950 节点约 19.5 MB 状态保存、恢复与重启。 |

模拟客户端、回环网络和 ARM64 指令模拟覆盖了上述工作负载。实际用户通过公网反向代理连接时，延迟和吞吐还取决于机器、显示设备、网络与代理配置。
