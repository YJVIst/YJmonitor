# 羽迹探针 Rust 运维与恢复

主控 0.11.5，Agent 0.2.3。已有站点升级时保留完整 `storage/`，不要重新安装向导。版本管理中的升级与回退使用已登录管理员会话，不再次要求密码；备份、安全设置等敏感操作仍要求近期密码验证；开启二步验证后，还需动态码或未使用的恢复码。

## 恢复码与丢失验证器

启用二步验证后显示 10 条恢复码，每条有 128 位随机熵，只能使用一次。服务端仅保存摘要。请下载到密码管理器，勿放入公开源码。

登录时输入正常密码，在验证码栏填写恢复码；恢复登录会撤销原有管理会话。进入“面板设置”，用密码和另一条未使用的恢复码关闭旧验证器，再绑定新设备。“账户安全”可以重新生成恢复码，旧批次立即失效。

恢复码也遗失时，使用服务器 root SSH。先停止本实例服务，命令会拒绝在服务锁占用时执行。

Debian 一键安装示例：

~~~sh
systemctl stop YJ.service
/opt/YJ/bin/probe-linux-amd64 --reset-mfa -state /var/lib/YJ/control
systemctl start YJ.service
~~~

按提示手工输入 `RESET MFA` 才会执行。arm64 改用 probe-linux-arm64。用户名、密码保持原值；验证器及恢复码清除，旧会话失效。

宝塔独立 Rust 服务示例：

~~~sh
systemctl stop YJ.service
/opt/YJ/bin/probe-linux-amd64 --reset-mfa -state /var/lib/YJ/control
systemctl start YJ.service
~~~

路径及服务名须替换为实际实例。只停止这一探针实例的 Rust 服务，不停止其他网站。

## 登录设备与远程管理

“账户安全”显示来源 IP、浏览器、登录时间、最近活动和远程会话数。撤销设备时关闭其身份和 SSH/SFTP 连接。真实 IP 应按可信代理配置获取，不能无条件相信访客转发头。

SSH 与文件管理仅管理员可用，遵循远程 SSH 账户权限。每次操作校验有效会话、节点状态及已固定的 SSH 主机指纹。

## 加密备份

在“备份迁移”填写不少于 12 字节的口令，下载 .backup。包含账户、站点、节点凭据、SSH 指纹、通知与常用命令；不包含 Nginx 配置、HTTPS 证书或其他应用文件。

使用 PBKDF2-HMAC-SHA256（600000 次、随机盐）与 AES-256-GCM。口令错误或密文篡改时拒绝导入。备份与口令分开保管，遗失口令无法解密。

自动备份周期为 6/12/24/168 小时，保留 1–30 份，位于私有 `storage/control/backups/`。自动备份口令由面板主密钥加密保存。请定期下载到其他设备，同机备份无法覆盖磁盘丢失。

压缩加密数据约 16 MiB、解压明文 128 MiB 上限；超过限制明确报错。更大实例可停本实例后另外加密备份完整 storage。恢复提交日志覆盖核心配置，进程中断后在启动时继续提交。

## 新服务器、新域名迁移

1. 旧主控先将节点升级为 Agent 0.2.2，确认上线，安装专用 SSH 恢复公钥。
2. 导出加密备份。尽可能停止旧主控，避免双主控争用。
3. 新服务器解析域名、配置有效 HTTPS，完成新安装向导。
4. 登录“备份迁移”，选择旧备份、口令，确认恢复。
5. 用备份中的管理员及二步验证重新登录，在“版本管理”查看迁移状态。

新站保留当前 origin；域名变化时经固定 SSH 指纹及专用恢复密钥主动连接节点，更改 WSS 地址，轮换 Token、终端密钥及恢复密钥。节点确认新 WSS 正常后完成；目标不可达则回到原配置。

旧主控不可达仍可恢复，但需要备份含匹配的恢复密钥、节点已安装对应通道、SSH 可从新主控到达、SSH 指纹未变化、新域名 DNS 和证书有效。旧 Agent 缺少恢复通道或 SSH 不可达时任务会提示并可重试，也可填写 SSH 密码重新部署；不会绕过证书或指纹验证。

同域名迁移可在恢复备份后切换 DNS，避免旧主控同时在线。修改页面站名不等于更换连接域名。

添加已有 Agent 的服务器并通过 SSH 密码验证后，自动替换本项目连接配置和专用密钥，保留其他公钥；失败恢复之前的 Agent 配置与运行状态。

## Telegram 通知与实时监控

在“Telegram 通知”填写 Bot Token 与 Chat ID。可选择上线、离线、续费、管理员登录事件；登录提醒默认关闭。预览只展示示例，点击“发送测试通知”才会发出测试消息。Token 加密保存，接口不返回明文。

消息显示状态标题、站点、服务器、UTC+8 时间及“打开面板”按钮；名称会进行 HTML 转义。离线持续 20 秒后提醒。续费提前 3 天触发，同日到期合并；“已续费”自动延长 30 天，“不再续费”停止该服务器提醒。

0.6.0 移除“节点策略”和“历史与流量”，停止长周期采样、流量账期与资源阈值告警。卡片、详情的实时监控、短时 CPU 趋势和网卡累计上传/下载保持可用。累计值来自系统网卡计数器，重启后可能归零。

旧备份仍可导入，其中的策略、告警状态和长周期历史会被忽略，新备份不再包含这些字段。升级前磁盘上的旧历史文件不再读写；需要保留旧数据时应保管升级前的私有备份。

## 移除节点

在线：下发固定清理操作，停用本 Agent、删除连接配置及面板专用 SSH 公钥，确认后删除记录。用户文件、其他应用与其他公钥保持不动。

离线：立即删除本地记录和凭据，不生成远程清理任务。服务器恢复后旧 Token 不能重新登记，需重新添加部署。

## Agent 更新与回退

“版本管理 → 升级 Agent”从固定 GitHub 仓库下载预编译资产，验证 Ed25519 签名、SHA-256、大小、架构及版本后安装。WSS 健康检查失败时回到原二进制与配置。

旧 Agent 通过已有终端通道安装受限管理入口。“回退 Agent”需要有效历史二进制和签名清单，首次安装没有上一版会明确提示。

## 主控签名更新器

Debian 一键安装自动配置。后台只提交固定操作与版本号，由 root 所有的 helper 从 YJVIst/YJmonitor 下载已签名包。浏览器不能选择任意路径、命令、仓库或下载地址。

更新前保留程序和私有状态快照，仅停止本实例服务。健康检查失败时恢复；手动回退也恢复当时数据，所以更新后的密码、设置或统计可能丢失，先导出最新备份。

宝塔环境先按部署教程建立独立 Rust 主控服务。假设服务为 YJ.service，root 核实后执行：

~~~sh
python3 /opt/YJ/ops/update-panel.py --configure \
  --name main --root /opt/YJ \
  --state /var/lib/YJ/control \
  --service YJ.service --origin https://probe.example.com \
  --listen 127.0.0.1:19282 --distribution rust
~~~

核实服务 ExecStart、服务用户及内部端口均只属于本站。更新器位于 /usr/local/lib/YJ/，root 配置在 /etc/YJ/update/，回退快照在 /var/lib/YJ-update/。未安装 helper 时监控及 Agent 管理正常，主控仍可按宝塔教程手动更新。

## 0.6.1 文件与终端调整

SSH 文件侧栏支持“新建文件”：填写文件名，在当前目录创建空文件后打开编辑器。同名文件、目录与符号链接不会被覆盖；已有未保存编辑时会先确认是否切换。取消文件选择不再关闭 SSH，标签编号始终跟随当前打开的会话数量。安装方式不变，无需重新部署 Agent。
